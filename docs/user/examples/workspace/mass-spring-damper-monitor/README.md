# Mass Spring Damper with NuRV Runtime Monitor

## Overview

This digital twin is derived from the Mass Spring Damper digital twin.

The mass spring damper digital twin (DT) has two mass spring dampers.
It shows how to use a co-simulation based DT within the DTaaS.
This version of the example adds a monitor generated by NuRV.
More information about NuRV is available on the
[NuRV tool page](https://es-static.fbk.eu/tools/nurv/).

## Example Structure

The study includes two simulators, each representing a mass spring damper
system. The first simulator calculates the displacement and speed of mass
$m_1$ for a given force $F_k$ acting on $m_1$. The second simulator
calculates the force $F_k$ from a given displacement and speed of mass
$m_1$. Coupling the two simulators computes how the positions of the two
masses evolve.

A monitor added to the simulation checks at runtime whether the
displacement of the two masses stays below a maximum threshold.

## Run the example

To run the example, change to the example directory.

```bash
cd /workspace/examples/digital_twins/mass-spring-damper-monitor
```

If required, make the lifecycle scripts executable, for example:

```bash
chmod +x lifecycle/create
```

Then run the following scripts.

### Create

- Installs Open Java Development Kit 17 and the pandas and matplotlib pip
  packages in the workspace.
- Generates and compiles the monitor FMU from the NuRV specification.

```bash
lifecycle/create
```

### Execute

Runs the digital twin. Because this is a co-simulation based digital twin,
the Maestro co-simulation tool runs a co-simulation of the FMU models.

```bash
lifecycle/execute
```

### Analyze phase

Processes the co-simulation output and saves a plot in
`/workspace/examples/data/mass-spring-damper-monitor/output/plots`.

```bash
lifecycle/analyze
```

Here is a sample plot.

![sample plot](mass-spring-damper-monitor_plot.png)

The plot uses three colours. The blue line is the distance between the two
masses, and the green line is the monitor's verdict. The red dashed line
marks the distance threshold that the monitor checks. The distance between
the masses always stays below the threshold, so the monitor output stays at
`unknown` (`0`).

#### Examine the results

The results are in the
_/workspace/examples/data/mass-spring-damper-monitor/output directory_.

The run logs are in
_/workspace/examples/digital_twins/mass-spring-damper-monitor_.

### Terminate phase

Removes the debug files and co-simulation output files.

```bash
lifecycle/terminate
```
