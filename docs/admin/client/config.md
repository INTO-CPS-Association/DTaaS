# Configure Client Website

This page describes the configuration options for the React website.
The options are set in `env.js`, which defines `window.env`.

  ```js
  if (typeof window !== 'undefined') {
    window.env = {
      REACT_APP_ENVIRONMENT: "prod | dev | local | test",
      REACT_APP_URL: "URL for the gateway",
      REACT_APP_URL_BASENAME: "Base URL for the client website"(optional, can be null),
      REACT_APP_URL_DTLINK: "Endpoint for the Digital Twin",
      REACT_APP_URL_LIBLINK: "Endpoint for the Library Assets",
      REACT_APP_CLIENT_ID: 'AppID generated by the GitLab OAuth 2.0 provider',
      REACT_APP_AUTH_AUTHORITY: 'URL of the private GitLab instance',
      REACT_APP_REDIRECT_URI: 'URL of the homepage for the logged in users of the website',
      REACT_APP_LOGOUT_REDIRECT_URI: 'URL of the homepage for the anonymous users of the website',
      REACT_APP_GITLAB_SCOPES: 'OAuth 2.0 scopes. These should match with the scopes set in GitLab OAuth 2.0 provider',
      LOGGER_URL: 'Endpoint of the logger microservice, including the /logger prefix'(optional),
      // REACT_APP_VIZ_SIGNALS_URL: 'Address of the signals gateway'(optional),
      // REACT_APP_VIZ_ALLOWED_ORIGINS: 'Origins for images and embeds'(optional),
    };
  };

  // Example values with no base URL. Trailing and ending slashes are optional.
  if (typeof window !== 'undefined') {
    window.env = {
      REACT_APP_ENVIRONMENT: 'prod',
      REACT_APP_URL: 'https://intocps.org/',
      REACT_APP_URL_BASENAME: '',
      REACT_APP_URL_DTLINK: '/lab',
      REACT_APP_URL_LIBLINK: '',

      REACT_APP_CLIENT_ID: '1be55736756190b3ace4c2c4fb19bde386d1dcc748d20b47ea8cfb5935b8446c',
      REACT_APP_AUTH_AUTHORITY: 'https://gitlab.intocps.org/',
      REACT_APP_REDIRECT_URI: 'https://intocps.org/Library',
      REACT_APP_LOGOUT_REDIRECT_URI: 'https://intocps.org/',
      REACT_APP_GITLAB_SCOPES: 'openid profile read_user read_repository api',
      LOGGER_URL: 'https://intocps.org/logger',
    };
  };


  // Example values with "bar" as basename URL.
  //Trailing and ending slashes are optional.
  if (typeof window !== 'undefined') {
    window.env = {
      REACT_APP_ENVIRONMENT: "dev",
      REACT_APP_URL: 'http://localhost:4000/',
      REACT_APP_URL_BASENAME: 'bar',
      REACT_APP_URL_DTLINK: '/lab',
      REACT_APP_URL_LIBLINK: '',

      REACT_APP_CLIENT_ID: '1be55736756190b3ace4c2c4fb19bde386d1dcc748d20b47ea8cfb5935b8446c',
      REACT_APP_AUTH_AUTHORITY: 'https://gitlab.intocps.org/',
      REACT_APP_REDIRECT_URI: 'http://localhost:4000/bar/Library',
      REACT_APP_LOGOUT_REDIRECT_URI: 'http://localhost:4000/bar',
      REACT_APP_GITLAB_SCOPES: 'openid profile read_user read_repository api',
    };
  };
  ```

`REACT_APP_GITLAB_SCOPES` must be exactly
`openid profile read_user read_repository api`; the client rejects any
other value when it checks the configuration.

`LOGGER_URL` is optional. Workflow logging and remote logging are off
by default, and users turn them on in their account settings. When
`LOGGER_URL` is empty or missing, enabled logging keeps events in the
browser (IndexedDB). When `LOGGER_URL` is set and remote logging is on,
the configuration check requests `<LOGGER_URL>/health`.

## Domain Extensions and Live Signals

These keys are optional. A client without them runs every extension it was built
with and shows no live readings.

| Key | What it does |
| :--- | :--- |
| `REACT_APP_EXTENSIONS_DISABLED` | Ids of compiled-in extensions to hide, separated by commas, for example `'bim'` |
| `REACT_APP_EXTENSIONS_DEPLOYED` | Bundles of extensions to load at start, separated by commas, each under `extensions/<id>/`, for example `'extensions/soil/index.js'`. An entry may end in `#sha384-<hash>` |
| `REACT_APP_EXT_<ID>_<NAME>` | A setting of one extension, read only by that extension |
| `REACT_APP_EXT_BIM_MODELS_DIRECTORY` | The library folder the Buildings page lists, `common/models` when unset |
| `REACT_APP_VIZ_SIGNALS_URL` | The address of the DTaaS signals gateway, for example `https://foo.com/signals` |
| `REACT_APP_VIZ_ALLOWED_ORIGINS` | Origins besides this site that a `visualisation.json` may load images and embedded pages from, separated by commas, for example `'https://grafana.foo.com'` |

An extension built as a bundle is installed without rebuilding the client. Copy
the bundle to `extensions/<id>/index.js` next to `env.js`, which in the Docker
packages means mounting a folder such as `./extensions` at
`/dtaas/client/build/extensions`, and list its path in
`REACT_APP_EXTENSIONS_DEPLOYED`. The client accepts only paths of that shape on
its own origin. A bundle runs with the rights of the client, so install only
bundles you trust. A compiled-in extension wins when both have the same id.

To make the browser refuse a bundle that was changed after you installed it, add
its hash to the entry, for example
`'extensions/soil/index.js#sha384-<hash>'`. Only SHA-384 is accepted. Compute
the hash of the installed file with:

```bash
openssl dgst -sha384 -binary extensions/soil/index.js | openssl base64 -A
```

Update the hash each time you replace the bundle. A bundle whose content does
not match is not loaded, and the reason is written to the browser console.

With `REACT_APP_VIZ_SIGNALS_URL` set, the client asks the signals gateway for
the signals the open pages need and colours the pages with the readings. The
client proves who the user is with the user's GitLab access token, sent in the
`Authorization` header. No broker login reaches the browser. When the key is
set, the configuration check requests `<REACT_APP_VIZ_SIGNALS_URL>/health`.
Without it the client shows no live readings.

A `visualisation.json` names the sources of its images and embedded pages. A
`lib://` source from the library and a source on the client's own origin are
always allowed. An `http` or `https` source on another origin is shown only when
its origin is listed in `REACT_APP_VIZ_ALLOWED_ORIGINS`. The key is empty by
default, so another site's page is not framed unless an administrator allows it.
